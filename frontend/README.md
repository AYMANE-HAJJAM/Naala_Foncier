# NAALA FONCIER — Frontend

Next.js App Router UI connected to the NestJS API via Orval + TanStack Query.

## Setup

```bash
cp .env.example .env.local
npm install
```

## Generate API client

Start the backend first (`http://localhost:3001`), then:

```bash
npm run generate:api
```

Orval reads OpenAPI from `http://localhost:3001/api/openapi.json`.

## Run

```bash
npm run dev
```

App: http://localhost:3000

Browser calls `/api/...` (paths generated by Orval already include `/api`).  
Keep `NEXT_PUBLIC_API_BASE_URL` empty so the prefix is not doubled.  
Next.js proxies `/api/*` to `${API_INTERNAL_URL}/api/*` so auth cookies stay same-origin. Set `API_INTERNAL_URL=http://localhost:3001` locally and the backend HTTPS origin on Render, before both build and start. Never set a public API base URL alongside this proxy.
